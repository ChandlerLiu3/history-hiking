# 六只脚导出（收藏 + 自有行程）

把六只脚（foooooot.com）账号里的**收藏**和**自己记录的行程**批量导出成 GPX，落到 `data/liuzhijiao/`。

设计前提：**登录这一步交给你**。脚本只负责开一个真浏览器、等你自己登进去，然后接管后面的翻页和下载。账号密码不经过脚本，也不写盘。

## 装依赖

```powershell
pip install playwright
playwright install chromium
```

## 跑

```powershell
python tools/liuzhijiao_export.py
```

1. 弹出 Chromium 窗口，地址是六只脚登录页
2. 你自己输账号密码（有验证码也是你自己点）
3. 登录成功后不用管，脚本自动开始翻列表、下载
4. 登录态存在 `.cache/liuzhijiao-profile/`，下次跑不用重登

## 输出

```
data/liuzhijiao/
├── my/          自己记录的行程  <id>_<标题>.gpx
├── fav/         收藏的行程      <id>_<标题>.gpx
├── raw/         trackjson 原始数据（走了兜底路径的才留）
└── manifest.csv id,标题,来源,文件,点数,状态
```

`status` 取值：`ok`（官方 GPX）、`ok(trackjson)`（自己拼的）、`skip(exists)`、`fail`。

## 常用参数

| 参数 | 用途 |
|---|---|
| `--probe` | 只诊断不下载：打印各候选列表页能不能翻出行程、某条行程的下载链接长什么样 |
| `--only my` / `--only fav` | 只导一边 |
| `--limit 5` | 先下 5 条试水 |
| `--uid 123456` | 自动认不出你的编号时手动指定（个人主页地址里那串数字） |
| `--fav-url <完整地址>` | 收藏页自动探测失败时直接给地址 |
| `--force` | 覆盖已存在的文件 |

## 出问题了

- **收藏一条都没抓到**：先 `--probe`，看「收藏」那几行哪个候选页落地正常、行程链接数合理（比如 30 条），把那个地址用 `--fav-url` 传进去。收藏页的路径站点没公开文档，只能试。
- **认不出 uid**：打开你的个人主页，地址形如 `/userindex/123456/`，用 `--uid 123456`。
- **某条 fail**：多半是私有行程或已删除。清单里标了，不影响其它条。
- **报 python 语法/依赖错**：把完整 traceback 贴回来。

## 边界

- 只读：脚本不点赞、不评论、不修改任何东西。
- 有速率限制：默认每条之间隔 2 秒左右，别调太小。
- 导出的轨迹是**别人（或你自己）的实测记录**，不是史料。按 `preset/02-sources.md` 的规矩，引用时要写平台、行程 ID、作者、日期；它用来证明「这条路今天能走」，不用来替代史料定位。
