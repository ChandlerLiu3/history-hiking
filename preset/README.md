# 历史轨迹规划 preset

把史料里的路径，落成今天**有人走过、能复核**的线路。

核心原则：**先找成熟轨迹，再谈自建**。KML/GPX 只是线索的载体，不是目标——一条被多个队伍反复走通、有文字和照片佐证的现成轨迹，比一条自己拼出来的漂亮 KML 可靠得多。

适用于任何模型/任何会话。用法：把本文件与 `01-method.md` 交给执行者，或直接说「按 preset 规划 XX 路线」。

## 它解决什么问题

历史路线规划最容易出的三种错：

- **地名对不上号**：古今同名异地，直接开走。
- **想当然连线**：两点画直线，忽略垭口、渡口、河谷绕行。
- **拿自绘线当证据**：把推测画成轨迹，后来者无法复核。

preset 用「史料锚点 → 轨迹检索 → 成熟度评估 → 日段」四步，把「这条线今天到底能不能走」变成可核查的问题。

## 30 秒流程

1. **锚定**：史料里的地名 → 候选坐标 + 判据 + 置信度。
2. **检索**：两步路/六只脚/Wikiloc 上按关键词找现成轨迹，凑够覆盖该段的候选。
3. **评估**：按 M1–M3 打成熟度，冲突的轨迹并列，不取平均。
4. **切段**：8–15 km / 爬升 400–800 m，每段带撤退点。
5. **交付**：`segment.yaml`（含 `tracks[]`）+ `card.md`；GPX 只在无现成轨迹时才自建。

## 边界

- 管「规划」，不管「考证」。史料真伪由人判断，preset 负责结构与不确定性。
- 国内 1:5 万地形图涉密，用公开 DEM 与公开轨迹替代。
- 引用他人轨迹必须署名；OSM 数据遵循 ODbL。
