# 03 三级体系

同一套方法，三级不同的严格度与容错。级别由「这条线在整体计划里的位置」决定，不由长度决定。

## 对照表

| 维度 | L0 主线 | L1 支线（日段） | L2 踩线（支线的支线） |
|---|---|---|---|
| 例子 | 长征全线、褒斜道全程 | 娄山关—桐梓、斜谷口—五丈原 | 凤凰岭南线半日 |
| 尺度 | 跨月、跨省 | 1–3 天 | 半天–1 天 |
| 史料要求 | 每段有出处，主要节点 A/B | 关键节点有出处 | 只需地理位置正确 |
| 轨迹要求 | M3 + 多源，且分段各自有 M2 | 每段至少 1 条 M2 | 1 条 M2 即可，M1 可接受 |
| 容错 | 偏差 5 km 内需解释 | 偏差 2 km 内需解释 | 走岔了能退回即可 |
| 撤退要求 | 每日段有撤退方案 | 每段有撤退点 | 有手机信号/公路在 3 km 内 |
| 产出 | 总览 + 全部日段 + 补给/交通表 | segment.yaml + card.md | 一页卡片 + 轨迹链接 |
| 允许的推测 | 少量，须标注 | 常见，须标注 | 不追究，但需说明 |

## L2 的定位（重要）

L2 是「支线的支线」，作用是**热身、踩线、验证装备与体力**，不是历史考据。所以：

- 不要求与史料路径吻合，只要求**安全、成熟、可复现**。
- 优先选景区步道、成熟环线、有明确撤退点的线路。
- 一条 M2 轨迹 + 一张卡片就够，不必做锚点表。
- 唯一硬指标：当天能下撤。

## 升级规则

- L2 走通后，若该段与某条历史路径重合，可升为 L1 的踩线依据，但仍需补锚点。
- L1 的多个日段走通，且史料链条闭合，才可归入 L0。
- 降级随时允许：证据不足就降，不丢人；把 C 级写成 A 级才是事故。
